## 两边用的不是同一套信号

文字检索主要看页面文本和链接关系;图片检索主要看图片周边的文本、来源页面,以及那张图被传播的广度。

**传播度这个因素在图片侧的权重高得多。** 一个梗图、一张明星照片、一个热门角色的图,它们的传播量远超任何一个小众商业品牌的官网截图。

⇒ 所以在名字撞上高传播内容时,**图片条几乎必然被那一边占据**,而文字结果可能完全正常。**这不是矛盾,是两套排序各自在做对的事。**

## 冲突时先信文字

对于「找一个商业服务」这个目的,文字结果通常更接近目标。

原因是文字结果的排序更看重相关性和内容实质,而商业服务的官网、评测页、讨论页都是文本形态。**图片形态的信息在这类查询里本来就不是主要载体。**

⚠️ 但有一个例外要注意:**如果文字结果里也几乎没有这个服务,只是零星出现,那图片条的占据就不再是「无关干扰」,而是一个佐证** —— 说明这个名字在公众认知里主要指代另一个东西。

## 图片条的正面用途

虽然不该用它做归属判断,图片条有一个实际用途:**它能在三秒内告诉你这个名字还指代什么。**

这对后续有帮助。知道了这个名字同时指代一个人名和一个梗之后,你在读文字资料时就会主动做归属判断,而不是默认每条都在讲你要找的那家。

⇒ **用它做背景了解,不用它做结论。**

## 一个容易忽略的方向

反过来的情况也存在:**图片条里出现了这个服务的官网截图,而文字结果里它排得很靠后。**

这种情况下图片条反而提供了一个线索——至少说明这个服务有可被抓取的视觉内容存在。**但它同样不能证明入口有效或服务正常**,截图可能是很久以前抓的。

⇒ 无论哪个方向,**图片都只提供存在性线索,不提供时效和状态。**

## 一套可复查的核验流程

### 第一步:分别看文字和图片,不要混着看

先各自记下它们指向什么。**混着看会得到一个模糊的印象,而不是两个清楚的观察。**

### 第二步:冲突时以文字结果为准

对于找商业服务这个目的,文字结果更接近目标。

### 第三步:但要检查文字结果里这个服务占多大比重

如果文字里也只是零星出现,那图片条的占据就是一个佐证而不是干扰。

### 第四步:用图片条了解这个名字还指代什么

三秒就能看完,对后续的归属判断有帮助。

### 第五步:不要用图片判断时效或状态

截图可能是很久以前抓的,它只提供存在性线索。

### 第六步:用服务本身验证

能否登录、剩余额度是否与记录一致、工单是否有人回、公告是否连续。

## 不同检索形态各自会被什么主导

把这件事推广一下,同一个查询下不同形态的结果可能指向不同实体,原因是各自的排序信号不同:

```
文字    内容质量与相关性       ⇒ 商业实体在这里更容易出现
图片    传播广度              ⇒ 梗图、人物、热门内容占优
视频    标题与频道权重         ⇒ 娱乐类内容占优
答案框  格式规整度            ⇒ 表格和列表占优
```

⇒ **看到某一栏被无关内容占满时,先问那一栏靠什么排序**,而不是直接推断这个词本身有问题。

## 对判断的实际影响

知道这一点之后,读搜索结果的方式会变:**你不会再把一页里所有区块的信号当成一个整体。**

图片条被占满、视频区全是娱乐内容、而文字结果里这个服务好好地排着——**这三件事可以同时成立,而且都是正常的。**

⇒ 判断时只用和你的目的匹配的那一栏,其余当背景。**对找商业服务而言,那一栏是文字。**
